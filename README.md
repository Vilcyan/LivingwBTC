# BTC Portfolio

Trang portfolio Bitcoin tĩnh, được xuất từ Instinct File. Dữ liệu hiện là snapshot ngày 20/09/2026.

## Chạy tại máy

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Thư mục `dist/` có thể được deploy lên GitHub Pages.

## Quyền riêng tư

Source hiện chứa đầy đủ lịch sử giao dịch, số BTC nắm giữ và giá vốn của chủ sở hữu. Không publish Pages hoặc chuyển repo sang public nếu chưa chủ động chấp nhận công khai dữ liệu này.
